## The word

> mutkibubu

The entrant's own make.fun username. The judge's first criterion is
that the entry is a real make.fun username, the entrant's own handle sent
as one word — a genuine handle beats any invented word. One word, nine
characters, no spaces, no gloss: a name its owner happily wears, and one
that sticks in the mind after a single look.

## Run it

```sh
node main.ts
```

This writes the word to `/output/entry.txt` (10 bytes: `mutkibubu` + newline),
valid UTF-8, well inside the 1–30 character gate — and prints it to stdout.
